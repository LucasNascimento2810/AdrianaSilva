# Passinhos — Prévia para Adriana Silva

Protótipo navegável de um aplicativo para apresentar a proposta de atividades de estimulação motora infantil por faixa etária.

> **Status:** demonstração comercial; não é um produto clínico finalizado.

## Como acessar

Abra o `index.html` diretamente no navegador ou importe este repositório como projeto estático na Vercel.

## O que a demonstração permite

- Consultar atividades organizadas por faixa etária;
- Navegar por um plano semanal e pelo catálogo;
- Filtrar atividades, favoritar e visualizar o passo a passo;
- Utilizar o cronômetro e registrar atividades realizadas;
- Consultar o diário de atividades e observações;
- Acessar um painel demonstrativo para cadastrar, salvar como rascunho e publicar atividades.

## Limitações desta versão

- Os registros são armazenados no `localStorage` do próprio navegador; **não há sincronização entre dispositivos**;
- Não possui contas reais, autenticação, banco de dados, notificações ou pagamentos;
- O conteúdo e as recomendações são ilustrativos e precisam ser revisados e aprovados por Adriana antes de qualquer uso com famílias;
- O nome e a identidade visual são provisórios.

## Publicar na Vercel

1. Acesse [New Project](https://vercel.com/new/import).
2. Importe o repositório `LucasNascimento2810/AdrianaSilva` do GitHub.
3. Configure a pasta raiz como `./` e o framework como **Other** (site estático).
4. Deixe **Build Command** e **Output Directory** sem substituições personalizadas.
5. Clique em **Deploy**.

A Vercel disponibilizará um endereço público e poderá publicar novas alterações enviadas à branch `main` depois que o repositório estiver conectado.
